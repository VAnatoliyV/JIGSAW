# Albion Journal - SFX library & SFX track

Synthesised in code (numpy/scipy, no samples), fully deterministic. Generated by `audio-src/sfx/build_sfx.py` - **do not hand-edit; re-run the build** (this README is regenerated).

```
python3 audio-src/sfx/build_sfx.py             # library + track + verification + this README
python3 audio-src/sfx/build_sfx.py --no-verify # fast: library + track only
```

## Outputs

- `sfx_track.wav` - 48 kHz / 24-bit stereo, exactly 120.000 s, assembled from `timeline/timeline.json` (203 events).
- `sfx_cues.json` - every placed event: timeline time, accent time, variant, start sample, gain.
- `oneshots/*.wav` - the one-shot library (48 kHz / 24-bit stereo) + `oneshots/index.json` (anchor offsets, levels).
- `oneshots_sheet.png` - contact sheet: waveform + spectrogram of every one-shot, anchor marked.

## Sync rule (anchors)

Each one-shot carries an **anchor** = sample of its perceptual accent (`anchor_s` in index.json). The assembler places `start = round(accent_time * 48000) - anchor`, so:

- impact, hit, stamp, anvil, coin, fire, sparkle, glint, zap, click, key, pop, tick: transient peak on **t**
- whoosh, swell: loudest point on **t + dur** (the cut / downbeat)
- riser, reverse: abrupt end on **t + dur**

Variation: impacts alternate 2 variants per strength, hits 4, stamps 3, clicks 3, ticks 4, whooshes 4 (and alternate L->R / R->L), every keystroke is unique (seeded per key, SPACE has its own variant), pops climb the D-minor pentatonic ladder D5 F5 G5 A5 C6 D6 F6 G6 A6 C7 within a cascade (a gap > 0.75 s restarts on D5). `vel` scales gain linearly.

Master chain: sum -> zero-latency look-ahead soft limiter (4x oversampled true-peak detector, 3 dB soft knee, 4 ms look-ahead ramp, 120 ms release, ceiling -1.3 dBTP) -> 30 ms end fade. The limiter is gain-only with no delay, so it cannot move any accent.

Mixing note: the stem is balanced internally (impacts own the top few dB; in 50 ms loudness pops sit ~11 LU, clicks ~16 LU, keys ~20 LU and ticks ~25 LU (before vel) under an S3 impact) and is safe to drop in at unity for true peak. Under music + VO start the SFX fader around -4 to -8 dB and ride the drops (16, 96, 104, 116 s) against the orchestral hits.

Per-type mix trims (dB, `TYPE_TRIM_DB` in build_sfx.py): impact +0.0, hit +0.0, stamp +0.0, whoosh +0.0, swell +0.0, riser +0.0, reverse +0.0, fire +0.0, coin +0.0, anvil +0.0, sparkle +0.0, glint +0.0, zap +0.0, click +0.0, key +0.0, pop +0.0, tick +0.0
